LatentLoop: Scaling Looped MoE Models with Asymmetric Compute Allocation

Paper Code
OVERVIEW

Abstract

A different allocation
for a shared model.

Looped Mixture-of-Experts (MoE) models combine parameter reuse with sparse computation to improve performance under matched budgets. Prior work demonstrates that different loop visits can play different roles even when they share parameters. To probe the contributions of different loop visits, we learn separate residual coefficients in a model that applies a shared block twice, observing a smaller scale in the first visit. Fixed coefficient experiments show that reducing the first visit’s scale preserves or improves performance, whereas the same reductions to the second hurt it.

This asymmetry motivates us to explore asymmetric compute allocation. We propose LatentLoop, which compresses the first visit’s sequence, retains full resolution in the second, and reallocates saved computation to increase the hidden size. We further learn how strongly the first visit updates the full sequence, and share MoE weights across visits while using separate attention parameters to accommodate their different sequence resolutions.

Across 15 configurations spanning 1.3B–7B parameters, with the largest budget exceeding 1021 FLOPs, LatentLoop consistently lowers validation NLL. At a fitted NLL of 1.988, predicted compute savings are 19.0% relative to MoE Base and 7.9% relative to MoE Loop. It also improves average scores on nine benchmarks at all sizes in 0-shot and 5-shot settings. These results suggest asymmetric compute allocation is a promising direction for looped MoE models.

03 THE ARCHITECTURE

Compress once.
Refine at full
resolution.

The first visit operates on a shorter latent sequence. The second processes every token. We reallocate the saved computation to a wider model.

  1. 01

    Encode the sequence

    A simple mean encoder aggregates pairs of states into T/2 latent positions, preserving the channel width.

  2. 02

    Compute in latent space

    The first visit processes fewer positions, using the full model width and the same number of active experts per position.

  3. 03

    Calibrate the writeback

    Learned coefficients control how strongly the latent increment updates each channel and receiver position, with causal alignment.

  4. 04

    Revisit the full sequence

    The second visit processes all T positions. MoE blocks are shared; attention blocks have independent parameters.

04 THE RESULT

Better allocation.
More efficient scaling.

LatentLoop achieves lower validation NLL at all 15 matched budget endpoints. Fitted compute-optimal frontiers quantify the computation needed to reach the same loss.
